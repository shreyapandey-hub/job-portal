# 💼 Job Portal

A modern and responsive **Job Portal web application** built to help users explore job opportunities and find jobs according to their skills, location, and career interests.

## 🚀 Features

- 🔍 Search for jobs by title, skill, or company
- 📍 Search jobs by location
- 💼 Display latest job openings
- 🏢 Company-wise job information
- 📄 Detailed job cards with:
  - Job title
  - Company name
  - Location
  - Salary
  - Job type
  - Work mode
- 🔖 Save/bookmark jobs
- 👤 Login and Sign Up interface
- 📱 Responsive and user-friendly design

## 🛠️ Technologies Used

- **HTML5** – Structure of the web pages
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and interactions
- **React.js** – Component-based frontend development

## 🧩 React Components

The project is divided into reusable components to make the application organized and easy to maintain.

Some major components include:

- `Navbar`
- `HeroSection`
- `SearchBar`
- `JobCard`
- `JobList`
- `Footer`

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/job-portal.git
```

### 2. Go to the project directory

```bash
cd job-portal
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on the local development server provided by Vite.

## 🎯 Purpose of the Project

The main purpose of this project is to create a simple platform where users can:

1. Search for available jobs.
2. Explore different companies.
3. Check job details.
4. Find suitable opportunities based on location and skills.
5. Easily navigate through job listings.
